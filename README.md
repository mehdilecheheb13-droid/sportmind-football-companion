# Sportmind Football Companion

Create a modern and responsive web application called SportMind AI.

The application is about football and artificial intelligence. The interface must be in French.

Create these pages:

1. Accueil: a welcome page with the SportMind AI logo and navigation.

2. Équipes: information about Real Madrid, FC Barcelona, Manchester City, PSG and MC Alger.

3. Matchs: a list of sample football matches.

4. Classements: a sample league table.

5. Statistiques: football statistics displayed with charts.

6. Assistant IA: a simple interactive football chatbot interface.

Design: dark navy background, purple and green accents, modern football dashboard, clean layout, responsive for computers and phones.

Use realistic sample data and clearly label it as demonstration data. Do not invent live match results or claim real AI integration without implementing it.

Make all navigation links and basic interactions work. Build a complete, attractive prototype suitable for a university project.
